# Granite 3.1 MoE routing reference

This directory contains a bounded, host-only correctness oracle for the
Granite 3.1 1B-A400M mixture-of-experts routing path. It does not compile a
Radiance kernel, access an FPGA, download a checkpoint, or model performance.

The reference fixes the official layer dimensions used by this workload:

| Quantity | Value |
| --- | ---: |
| Tokens in the representative invocation | 128 |
| Hidden width | 1024 |
| Experts | 32 |
| Selected experts per token | 8 |
| Expert intermediate width | 512 |
| Router weight shape | `[32, 1024]` |
| Combined gate/up weight shape | `[32, 1024, 1024]` |
| Down weight shape | `[32, 1024, 512]` |
| MoE output shape | `[128, 1024]` |

The implemented scope starts from router logits with shape `[128, 32]` and
checks:

1. deterministic top-8 selection, with lower expert ID winning exact ties;
2. softmax over only the eight selected logits, with FP32 rounding at each
   stored arithmetic boundary;
3. token-major assignment IDs, `assignment_id = token * 8 + rank`;
4. stable grouping by expert without changing assignment order; and
5. exact structural invariants proving that all 1,024 assignments occur once.

Synthetic deterministic logits are generated by default. This keeps the
oracle reproducible and independent of model downloads.

## Correctness boundary

Structural exactness is a zero-tolerance contract: selected expert IDs,
assignment IDs, expert counts, offsets, stable order, and inverse mappings
must match exactly.

Numeric equivalence is a separate contract and is **not** established here.
The official checkpoint uses BF16 weights and activations. An accelerated
Radiance path may quantize operands to MXFP8 and return BF16. Such a path must
eventually pass both a mapped-arithmetic MXFP8 oracle and a separately
reported error comparison against official BF16 inference. Passing these
routing tests alone does not imply either form of numeric equivalence.

## Usage

Run the tests:

```sh
python3 -m unittest -v kernels/granite_moe_reference/test_granite_moe_reference.py
```

Generate a complete JSON routing oracle:

```sh
python3 kernels/granite_moe_reference/granite_moe_reference.py \
  --output /tmp/granite-moe-routing-oracle.json
```

Without `--output`, the tool prints a compact validated summary.
